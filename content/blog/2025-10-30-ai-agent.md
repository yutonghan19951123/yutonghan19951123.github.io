This is a “visual-first” human–AI collaboration interface for adaptive traffic signal control. The system overlays semantic “ground truth” on live CCTV video. The overlay shows what the model detects, such as vehicles, regions, and threshold-based judgments. Operators do not need to simply trust the algorithm. Operators can see what the algorithm is using to make decisions.

## Background and Goal

Conventional smart-traffic platforms are strong at post hoc analysis. These platforms provide trends, reports, and historical patterns. The problem appears during real-time intervention. Algorithms can adjust signal timing in seconds. Many systems still fail to explain those adjustments. Operators can see outcomes, but operators cannot see reasons.

My goal is specific. I want the interface to turn real-time optimization from a black-box action into a verifiable workflow. I also want operators to supervise with less effort. The system should move people away from constant manual control. The system should support higher-quality monitoring and targeted intervention.

## Core Challenge: Opaque Automation

The central difficulty is not computation. The central difficulty is adoption. People hesitate when the system cannot be audited. That hesitation creates two costs.

The first cost comes from a trust gap. Operators remain cautious when AI decisions are not inspectable. Higher automation can increase that hesitation.

The second cost comes from cognitive load. Operators must manually review large volumes of video and data to validate each automated decision. That process is slow and exhausting.

## Approach: A Five-Step Loop That Turns a Black Box into a Glass Box

I broke a continuous optimization process into a discrete and verifiable loop. The system externalizes the agent’s working memory into a linear timeline. The timeline gives each decision a trace, supporting evidence, and replay.

The loop has five steps.

1. **Sense**: The system detects congestion risk.
2. **Verify**: The system provides visual checks for semantic ground truth.
3. **Propose**: The AI generates a strategy and explains its rationale.
4. **Deploy**: The system executes signal control automatically.
5. **Review**: Operators monitor outcomes and review decisions.

This structure changes the supervision task. Operators do not need to watch every second. Operators need to review each explainable decision. The system shifts supervision from constant attention to informed judgment.

## Key Contribution: A Canvas-Based Visual Verification Engine

I implemented a high-performance HTML5 Canvas overlay renderer on the front end. The system renders semantic layers on top of an H.265 live video stream. The overlay acts as a visual translator. The overlay turns backend judgments into graphical evidence that people can inspect.

- **Dynamic Tracking for On-the-Spot Counting Checks**

The interface draws real-time, color-coded bounding boxes and tracking IDs. Operators can compare YOLO detections with the actual scene. The system can also reveal where counting errors come from.

- **Zone Saturation Visualization for Visible Threshold Rules**

The interface draws AOI polygons to mark regions of interest. The interface displays zone-based saturation judgments in sequence. Operators can quickly verify rules such as “Zone 2 > 2 cars.”

- **Confidence Exposure to Make Uncertainty Explicit**

The interface displays model confidence values next to targets, such as 0.8. Operators can use the same evidence to decide what to trust. Operators can also decide when to intervene.

## LLM Interaction: From Parameter Panels to Natural-Language Commands

The interface combines visual auditability with natural-language control through an LLM. Operators can express intent in plain language. The system maps that intent into actionable control suggestions. The system also ties each suggestion to verifiable visual evidence. Operators can inspect the rationale before execution. This ordering reduces the risk of blind reliance on AI.

## Outcomes: Turning Expert Practice into a Transferable Workflow

The deployed system produced value in three ways.

First, the system shortened onboarding. The five-step loop reduced the learning curve for new operators. New operators learned how to judge, not how to memorize steps.

Second, the system improved auditability. The Canvas verification layer made AI reasoning visible in context. Operators could compare algorithmic logic with on-the-ground reality. Trust came from visibility, not from assurances.

Third, the system reduced supervision burden. Operators shifted from manual control to AI-assisted oversight. Operators could manage more intersections with lower cognitive load.

## Reflection: Research Questions Emerging from Practice

This project reinforced one point for me. Accuracy alone does not earn trust. Visibility of reasoning also shapes trust.

This experience also pushed me toward deeper research questions. I now ask how much visual complexity helps judgment without causing overload. I also ask how explicit uncertainty visualization affects human agency and trust. These questions connect directly to my Ph.D. motivation. I want to build more than usable tools. I want to extract principles for human–AI collaboration in high-stakes governance settings.
